# 페이트 코어 한국어판 (fate-core-ko)

Foundry VTT v13용 페이트 코어 시스템 — 비주얼노벨 스타일 연출에 특화된
한국어 TTRPG 시스템입니다.

## 주요 기능

- 🎭 **VN 대사창** — 최대 3인 초상화, 캐릭터별 표정(차분), 타자기 효과
- 📋 **대사흐름도** — GM이 장면을 미리 구성하고 대사·음악·연출을 순서대로 재생
- 🎲 **페이트 굴림** — 4dF + 난이도 판정, 면모 발현(+2/리롤)·운명점 자동 연동, 대결 굴림
- 🖥 **커스텀 UI** — 다크+골드 테마의 사이드바·무대·위젯·저널·다이얼로그 일체
- 🎵 **음악 연출** — 배경음/효과음 크로스페이드, NOW PLAYING, 흐름도 음악 노드
- 🌧 **화면·날씨 연출** — 흔들림·암전·번쩍임, 비·눈·안개 (전 플레이어 동기화)
- 📖 **커스텀 저널** — 디자인 템플릿 10종, WYSIWYG 편집, 플레이어에게 보이기
- 🖨 **기록 보존** — 채팅 로그 PDF 인쇄(디자인 적용) / 텍스트 다운로드

## 설치

Foundry VTT → 게임 시스템 → 시스템 설치 → 매니페스트 URL 입력:

```
https://github.com/Merry-kor/fate-core-ko/releases/latest/download/system.json
```

## 요구 사항 및 호환성

- **Foundry VTT v13** (verified 13.351)
- 본 시스템은 자체 사이드바 UI를 사용하며 **FVTT 기본 사이드바를 숨깁니다.**
  사이드바를 조작하는 모듈과 충돌할 수 있습니다.
- 캔버스(토큰·맵) 기능보다 **극장식(theater of the mind) 플레이**에 최적화되어
  있습니다.

## 빠른 시작

1. GM으로 접속하면 사용 안내 저널이 자동 생성됩니다 (저널 탭).
2. 설정 탭 → "⚡ 빠른 시작 콘텐츠 생성"으로 기본 기능 18종과 예제 캐릭터를
   만들 수 있습니다.
3. 액터 탭에서 캐릭터를 하단 무대 바로 드래그 → 발언권 선택 → 대사 입력!
